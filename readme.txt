نام پلاگین

== Description ==

توضیحات پلاگین 


== Features ==

* شارژ کیف پول با درگاه‌های پرداخت SEP و زرین‌پال


== Installation ==

1. فایل پلاگین را در پوشه `/wp-content/plugins/` آپلود کنید
2. پلاگین را از طریق منوی 'پلاگین‌ها' در وردپرس فعال کنید
3. تنظیمات را در منوی 'اسم پلاگین' انجام دهید

== Usage ==

شورت‌کدهای موجود:

* `[shortcode_name]` - عملکرد پلاگین
